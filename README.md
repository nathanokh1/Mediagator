# MediaMitigator

A Windows desktop application for consolidating photos and videos from multiple drives into a single organized destination.

## Features

- 8-step wizard interface
- Scans multiple Windows drives for media files
- Organizes files by year/month using EXIF and metadata dates
- Duplicate detection and routing
- Copy-verify-delete with transfer state for resume
- HTML reports and optional Lightroom import path export
- Windows toast notifications and optional email alerts
- Dark theme UI

## Requirements

- Python 3.12+
- Windows 10/11

## Setup

```bash
pip install -r requirements.txt
python src/main.py
```
